# Bundled fonts

Embedded in the binary so the Galdr look works on systems that do not ship them.

| File | Font | Use | License |
|---|---|---|---|
| `NotoSansRunic-Regular.ttf` | Noto Sans Runic | real Elder Futhark characters (icons, seals, rune field) | see `LICENSE-noto.txt` |
| `BigShouldersDisplay.ttf` | Big Shoulders Display (variable) | wordmark and display titles | SIL OFL 1.1, https://github.com/xotypeco/big_shoulders |

Body text uses the system sans-serif and data uses the system monospace.
