Console first

Every button is a shortcut.

Bamboo never hides what it does. Pressing Install opens a visible terminal and runs the same line you see in the details, with a copy button. Prefer your own shell? Copy it and go.

ᛒInstall Bamboo End Store AUR
yay -S bamboo-end-store
paru -S bamboo-end-store
Either helper works. The package builds Bamboo from source with Rust and Qt, so the first install takes a few minutes. Prefer to build it yourself? Steps below.
ᛊInstall · official
sudo pacman -S firefox
Opens in your terminal with sudo, asks for your password there.
ᚨInstall · AUR
yay -S spotify
paru -S spotify
Uses the AUR helper found on your system: yay or paru.
ᚠInstall · Flatpak
flatpak install flathub org.gimp.GIMP
Flatpak and Flathub setup is a button too, and shows its command.
ᚱUpdate system
eos-update
Then Flatpak, then orphaned packages. One click, one visible terminal.

The app only watches the exit code. Close the terminal and the job ends; nothing keeps running behind your back.

Install

Build it, run it.

Version 2 is a rewrite. Prefer the AUR (yay or paru, above). To build it yourself on Arch or EndeavourOS:

Source · dependencies
sudo pacman -S --needed base-devel rust qt6-base qt6-declarative qt6-svg qt6-wayland
Source · get and run
git clone https://github.com/satodu/bamboo-end-store.git && cd bamboo-end-store && ./run.sh --release

The first source build takes a few minutes. ./run.sh --clean starts with throwaway settings. The old 1.x app (Laravel and Electron) is kept under the tag v1.4.2-php.
